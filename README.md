# Tryout Scout

AI-powered soccer tryout assistant. A mobile web app where coaches speak observations during tryouts and the app converts them into structured player evaluations and roster recommendations.

## Documents

- [PRD.md](PRD.md) — Full product requirements document
- [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md) — 12-week day-by-day build plan

## Stack

- **Frontend:** Next.js (App Router, TypeScript)
- **Database / Auth:** Supabase
- **Transcription:** OpenAI Whisper API
- **AI Summaries:** OpenAI GPT-4o
- **Deployment:** Vercel
- **Dev Environment:** VS Code + Claude Code
